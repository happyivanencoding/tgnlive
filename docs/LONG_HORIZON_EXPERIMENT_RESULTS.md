## 五、Narrator 型号不是单一根因

同日又用 Gemini Developer API direct call 做了型号隔离实验，详见 `GEMINI_NARRATOR_MODEL_AB_2026-09-09.md`。固定相同 Canon / action / plan / Narrator prompt 后，Gemini 3.5 Flash 在驭兽 T18 的成长兑现场景中被两次匿名读者一致选为最佳小说感与最佳成长兑现；但在隐潮 T20 的路线观察场景，Terra control 两次都是最少流程化的版本，其中一次也被选为最佳小说。3.5 / 3.6 / 3.7 与旧 3 Flash 都会在该观察快照主动增加人数、车阵、泥地、巡逻、视线死角等细节。

`gemini-flash-latest` 在本机 direct API 实际解析为 **Gemini 3.8 Flash**。12 个固定快照共 220,511 token，纯 API 生成平均约 9.85s、首可见约 2.50s；按 2026 年 introductory paid 价格等价 $0.19390425，但该 key 的 429 明确命中 Free Tier quota，因此本轮实际 API 模型费用按 Free Tier 为 $0。结构层面 8/12 触发单次 repair，最终仅 6/12 接受。对这 6 个有效 Gemini 样本与对应 Terra 原正文随机换位盲比后，逐组解码均选择 **Terra 6/6** 作为更少流程化、更符合人物/力量/欲望/所得重心的版本；Gemini 常额外展开时间死角、路线、承重、跨度、扣环、榫口和受力规格。

因此“换模型”有真实影响，但目前不能解释长期工程化的主要来源；**直接换成 Gemini 3.8 Flash 反而被本组实验否定**，也不能替代上游对**本阶段值得发生什么主要剧情**的约束。当前最值得继续的组合实验是：每三回合由 Story Brain 生成 5–6 条互斥剧情方向，从源头规定事件/欲望/所得，再比较 Terra 与 Gemini 3.5 Flash 对同一已选方向的实现，而不是直接全局切换 Narrator。
