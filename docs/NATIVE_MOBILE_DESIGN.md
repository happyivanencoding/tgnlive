# Native Mobile：阅读优先的交互设计

这是 Android 候选客户端的设计与验收约束，不是“达到 JingYou 完成度”的声明。实现见 `apps/android/`；实际验证状态见 `NATIVE_MOBILE_TESTS.md`。JingYou 仅用于只读学习 Compose 工程、触感和系统适配，不复制其健康 dashboard 视觉。

## 核心结构

Discover 展示后端真实世界、最近书卷和一句话创建入口；书架只列同一服务的真实存档。创建使用既有世界生成接口，经过世界预览、天赋、主角命名和既有成年确认进入故事。阅读时隐藏主导航，正文占第一视觉层级，输入始终是独立、明确的行动入口。

阅读页由轻量标题/位置、原生 LazyColumn 正文和贴底行动坞组成。状态通过原生 ModalBottomSheet 按需打开，不常驻一排 RPG 数值。三个建议可以选择，但点击后进入可编辑的自由输入框；不直接把玩家锁在三个按钮里，也不多增加一个确认弹窗。

纸感亮色与深墨色暗色分别定义背景、surface、正文、辅助文字和分割层级。金色只用于少量强调，不用满屏发光、粒子或低对比透明层。正文最大宽度 680dp；窄手机以真实可用宽度排版。五档字号不是全局关闭系统缩放，输入继续保持可读的正常字号。

## 正文与滚动约束

已提交段落的 key 使用 gameId / turn index / paragraph index；暂定正文使用预计下一回合的同一 key 空间。模型 chunk 只改变当前暂定段落，不每次重建历史列表。正式 complete 使用服务器 game/turn；不通过 UI 自己结算能力或库存。

只有处于跟随模式时才跟到新增正文。玩家向上拖动必须立即关闭跟随；返回最新是显式动作。不要因为 complete、建议出现、状态层更新、字号或键盘变化就强行夺回滚动控制。草稿与阅读锚点按书保存，快速切书必须拒绝旧请求晚到。

段落布局、历史锚点、预览转正式正文、长段落换行以及键盘导致 viewport 变化都需实际 geometry 观察。稳定 key 和单元测试只是实现手段，不等于已证明不跳动。

## 行动坞与键盘

TextFieldValue 保留光标、selection、composition 和多行编辑。建议填入后可以直接改写。发送上限遵循同一 API 的 500 字符限制；等待时仍可编辑下一条草稿，当前回合完成不得删除玩家后来新写的文本。

`adjustResize`、edge-to-edge 与 Compose imePadding 需在同一层消费 insets，避免双重 padding。IME 出现后优先收起建议，保留输入文字、光标和发送/停止。紧凑横屏不能仅把 minLines 改成 1：要根据实际剩余 viewport 收起非必要标题、工具栏和计数，必要时把发送/停止并入输入区，防止整个 dock 高过屏幕。

真实 Gboard/Samsung Keyboard、中文组词、阿拉伯语混排、长文本选中/粘贴、系统 Font Scale、横屏 IME 与导航栏全部属于后续实际接受检查；当前不得标为已通过。

## 等待、触觉、动效

点击发送先同步进入 pending 并给轻量系统触觉，再等待网络；不能等服务端回包才改变按钮。公开状态只表达“世界回应/整理局势/继续故事”等真实可见阶段，不暴露 Story Brain 隐藏计划、模型推理或假的百分比。第一段真实文字显示后撤下等待提示，保留暂定状态直到正式提交。

触觉使用 Android 系统语义反馈并遵循系统/应用开关：选择/发送轻；首次真正可见正文或重要正式成长有区别；明确失败给克制提示。每个事件最多一次，历史回读、重组 UI、切回来或打开旧书不能再次冒充获得奖励。实际振动强弱与舒适度留给实体设备，不由代码 pattern 宣告通过。

页面和 sheet 使用一致的短过渡、受系统动画设置约束的弹性按压；不在每个 SSE chunk 上跑布局动画。正文不做逐字跳动、持续大 shimmer 或长 loading spinner。阅读场景中的低打扰比截图上的装饰更重要。

## 状态的业务含义

| 玩家看到的区域 | 同一服务端含义 |
| --- | --- |
| 当前境界/力量身份 | realm、benchmark、unlock |
| 能力 | power / capabilities：实际能做什么 |
| 携带 | inventory：已真正获得的物品与数量 |
| 人物 | relationships：态度、角色与作用 |
| 长期筹码 | progression.leverage：可调用关系、身份、入口、资产，不是技能 |
| 机会 | 已明确可争取的 opportunities；fulfilled 轻量归档 |

普通 facts 不触发奖励轰炸。重大反馈只能来自服务器确认的能力/境界/身份等真实变化；本客户端不加新的成长评分器、奖励补写或移动专属 progression。

## 五语与可访问性

UI 从首版保留 zh/en/fr/es/ar 的完整资源，默认中文；切换 UI 语言不翻译或改写已提交历史。新的请求携带所选语言，世界展示使用对应列表接口。阿拉伯语使用 RTL 布局，历史段落依据该回合记录的语言决定文本方向；返回等语义方向图标按含义处理，而不是所有图标统一镜像。

标签、错误、等待、设置、输入提示、状态标题和可访问性描述都要走资源。允许正文/世界专名保留自身语言，不能把后台字段名当玩家文案。系统大字号下优先换行与自适应，不全局压小 Density/fontScale。
