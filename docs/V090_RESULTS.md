已发布并核验：**v0.9.0**，生产代码提交 `6b59581a123494cfe393d68030369822735445d5`，原站4317与owner-only Access保持不变；28本旧书、131个历史回合、13个显式世界快照及全部8张持久表在部署前后逐表内容一致。正式部署与公网边界回执见 `artifacts/reports/ascension-v090/DEPLOYMENT.json`。这不是长期留存或所有成长循环已经解决的宣告。

本文件记录真实实验与接受边界，不把阶段名、字段数量或成功跑完当作成熟产品。生产是否已经发布，以 `artifacts/reports/ascension-v090/DEPLOYMENT.json` 的实际回执为准；本轮起点是已核对的 `26fc8e1` / v0.8.0。

## 问题重新定义

v0.8 的主要缺口不是“奖励太少”，而是三个环节没有闭合：世界已有公开规则，却没有在玩家必须决策前释放；Canon 能力与阶段身份被不相关的100进度门槛分开；规划将取得条件不断改写为下一项主要目标。于是角色账面不断积累，但玩家仍在修封口、找下一段线索或做小服务。隐潮的职业化不只来自叙述：原天赋成长终点明确写了卖验证服务，第一阶段出口也写着接正式委托。

本轮先改公共信息释放与阶段契约（A），完整长测证伪“这样就会成长”；再改规划中的已完成环节、真正未满足条件和行动粒度（B）；单独研究规划等待（C）；把隐潮的原料投入与第一刻式变为真实可选路线（D），并继续检验第一阶段社会出口（E）。不是一次大改后挑一条顺眼的轨迹。

## 证据口径

本轮已核验10条独立主轨迹、200个唯一成功提交回合；17次提交失败、3次独立Player失败另列，不重复统计恢复链。主要轨迹必须至少20个唯一成功提交回合。失败后沿原 `gameId` / Canon 继续，继承回合只算一次。原始失败与Player自身失败分开，正文预览不算提交。所有完整轨迹都有 `READING.md`、`PLAYER_DECISIONS.json`、`ACCOUNT.json`、`PHASE_TRACES.json`；最后汇总见 `artifacts/reports/ascension-v090/FINAL_MATRIX.json`。

API Player 是独立 Luna/low，未规定逐轮路线，但会看完整世界/状态，不能据此宣称真人只读正文也一定理解。驭兽C通过390×844真实Chrome页面操作，Player读页面正文、建议与公开状态面板；这比API更接近玩家观察，但仍不是物理手机、母语编辑或真人留存实验。动作不与建议逐字相同只说明能够自由输入，不是理解率或留存率。

## 开局与局势：保留改善，但不夸大因果

世界、力量来源、当前档位、下一档第一次能做什么、稀缺目标和自己的优势，原本散落在World中。现在第一次入场直接投影这些已有公开字段，在事件前用短正文释放；不是新模型、百科前言或完整等级表。人物换位/路线/利益明显变化时，允许直接更新局势与结果，有限POV整理公开动机而不泄漏秘密。

A万相的开场已经说明本命形态、印记和下一档，但20回合仍未得到第一印记，结尾反复练疏沟、安静绕行。A驭兽20回合从救兽转成盐料、旧码头、索具和下一条线索，甚至未实际发动共天眼。因此A的认知改善保留，A作为长期成长方案被否决。清楚地读懂一条无聊的循环，仍然不是本产品的成功。

B万相的第9回合真正拿到印核，第10回合完成承印，角色从初醒一级变为成印十级。正文写出了身体承载与双相操作，后面实际使用新能力，不是只改状态条。不过正式社会圈层的重新估价仍弱于物理成长：主要目击者是阿迟和云兽，不能把私下成功直接包装成全世界闻名。

C驭兽开场直接解释地行者/缚风学徒与共享感官、跨岛缝的差别。第8回合一次行动结算三天伤兽恢复与共同训练；第10回合成为缚风学徒；第14回合实际到达新岛；第18回合港口确认北漂旧航路共同申报身份。第19回合正式状态为一环驭手（不是旧摘要写的行云驭手）；正文表现心环分担一次冲击与共同转向，但没有明确报出正式境界名，稳定性与身份语言仍值得继续对齐，不能宣称语义错误消失。

## Mastery / 阶段：有可复用的改进，也有未毕业的循环

规划仍是原Story Brain的小JSON，增加可选 `growth.graduated` 与 `growth.transition`，没有新XP、技能库、身份树或任务系统。它必须区分终点与手段：哪些普通环节已完成，下一阶段真正还缺什么。Narrator按照玩家授权的完整范围结算成熟训练/往返/已掌握操作，保留新对手、新失效和新组合的细节，不替玩家擅自远征或付款。

B裂陆的区别最明确：第8回合复测失败，第9回合补足脚下与呼吸短板后成为通劲段；第10回合教头认可成绩、免去重复入门测试；第11回合三晚课程在一个完整行动里结算。后续已有招式真正用于猎采，稳定交付取得可暂停的预订渠道，后段一次行动可处理多日训练。阶段不是按回合赠送，也不是满100自动升级。

但裂陆中后段仍有连续采草供货，公开战力还没有充分变成更高圈层、更大地图和独立战斗身份。第20回合是否继续留在通劲段，应看下一阶身体定义是否具备，不能为了消除rank0就把升级本身当评分配额。A驭兽的线索接力没有毕业；C驭兽也仍有重复演示与教学记档。Supporting Logic Compression已经能工作，但不是每个低层循环都自动消失。

### 旧Canonical阶段事件的真实回归

原v0.8驭兽16回合已多次共享视野、双向协作、跨越岛缝，却仍是地行者/进度30。`eval/stage-identity-incident.mjs` 读取原冻结文件，由独立Player选择下一行动，再通过真实Brain/Narrator生成一份后续提案；不写原数据库、不把这一回合计入20回合主实验。

新提案得到缚风学徒，原v0.8 reducer对**同一份提案**因进度不足拒绝，新reducer接受；原输入文件hash保持不变。这证明旧机械门槛确实能拒绝实际阶段身份，不能证明所有模型提出的突破都语义正确。新规则仍需明确相邻阶段、身体/控制稳定与必要资源；特殊天赋短暂借力、社会称号和偶然成功不等于掌握整阶段。阶段能力条目记录身体benchmark，不能把世界unlock描述自动兑换成组织资源或权利。

## 隐潮：个人能力更早成立，不代表已摆脱职业循环

D保留钱、配方、信用、工位和交易，但开局同一份已拥有原料可制保鲜墨赚钱，也可按完整公开方制雾息入身墨，投入第一道自己的身体刻式。两者共用一包材料，不能重复花用。错味校准的成长方向改为个人支式与组合，售卖校准仍可选择，却不再是能力终点。五种语言的实际定义同步，不写运行时翻译覆写层；旧角色的世界快照不重写。

D玩家选择入身路线，第3回合达到一式匠，并实际使用雾息式。之后为第二刻式取得配方、样墨和尾随鉴别本事，非凡成长比旧18回合纯服务样本更明确。然而第13—20回合再次大量配墨、做小服务、交订金、购买壳片，第二身体刻式仍没完成。另有报价约束漂移：第13回合保存的凭条写尾款上限22券，第20回合却报价并扣26券，钱从88变为62。先前草稿把它描述成“已证实的6券订金重复扣款”不准确；应按凭证上限与实际付款不一致记录，不能凭旧摘要推断账目。D不能称为“已经摆脱港口服务模拟”。

E只继续修最早残留出口：一式匠公开行动空间从“接正式委托”转向个人支式、绕开普通耳目与非凡者交换；具体隐市仍需真实入口/引荐，不自动放行。开局payoff也不再写固定“一到三回合”要求；同时补明确的已有订金/抵扣/剩余尾款契约。测试中删除的是强迫保留那个数值口号的单元断言，不更换质量judge，也不把schema检查当作幻想改善。E已完成20个唯一成功回合。第4回合在夜航巡守中稳定雾息式；第6、9、10回合将能力用于巡记与短递。第11回合转向个人支式，第13回合制成定雾扣；第15—17回合购方、备料、受控入身，练成真正第二身体刻式折潮步并进入并式师。第18回合熟练刻制两枚定雾扣，没有重新拆成所有工序。第19回合欧岚明确认为“并式师跑普通巡记，确实太窄了”，给出临时副账航次；第20回合两式用于实际跨港交接，兑现鸥背港灰帆账会副账引介。不是墨页不坠，也不是雾门港，旧摘要混写已按实际正文纠正。尾段已有能力没有因换港清零；中段巡记/递运仍多，不能声称所有服务消失。

E改了阶段出口，同时启用已在C验证的prefetch；D/E不是只变一个变量的严格因果A/B，不能把全部改善都归功于一条World字段。更稳妥的结论是：具备早期个人能力、明确的非凡阶段出口与不会无限追加前置条件的规划时，本样本真正把材料/信用投入转成第二能力、社会位置与新港关系。星图最终续跑见下节。

## 星图最终20回合：能力升阶成立，社会升格仍不足

C星图沿同一Canon恢复到20。T10完成双核稳定维持，微光刻印→双轨回响；T12伊莱娅接受雾栖弱核优先供主角嵌入、其余平分的具体条件。T17在潮压中连续变换位置与方向，进入星环行者。T18—20确实用三核星环控制水路并进入潮钟库，不是只有账面升级。

但T20拿到三枚配重后，故事又指向“第四枚配重/下个入口”；大部分仍在同一遗迹圈内。没有足够证据称更高社会圈层已主动找上玩家。最终leverage为0，不是自动好消息：伙伴合作与分配筹码未持久化，存在漏记。旧capabilities仍有“不能长期双核同时”的限制，与新阶段矛盾。T10玩家明确失衡/白视就撤退，正文却安排他不退继续撑住；这种覆盖玩家停止条件的生成错误仍未解决，不能为了突破把它解释成成功。

## 公共证明与世界重新定价

B裂陆有真实折价、免试、长期预订；C驭兽有实际共同申报身份、正式航图交接和别人按其能力安排航段。它们比“态度+1”更接近世界重估。B万相更多仍是私下伙伴/兽群认可，D隐潮更多是商誉与渠道，尚不能说跨世界都已形成社会阶层跃迁。

Leverage收紧为反复可调用的人、准入、身份、独占渠道或产业。普通风路、地图知识和操作边界应进入facts/capabilities，既有旧记录不批量迁移或删除。实际样本仍有路线印记和临时转运类条目，因此“收紧”不是“彻底消除碎片化”。`useCount`等字段也不能代替正文判断；有些折扣实际用了却没更新计数。

## 等待：规划不再必须先于正文

C只把原低频Brain移到已提交回合之后提前执行，不降低effort、不添加每回合评审。基于第6/14回合Canon规划第8/16版本的方向；玩家下一行动未知，不预写已发生事实。只有同游戏、目标版本、语言、阶段匹配且已就绪才使用。未就绪、失败、过期或冷启动就直接用当前Canon和可用旧计划继续，不在用户点击后等待这份计划。当前动作与更新正文优先于提前计划。取消/换阶段/换游戏/退出会回收本任务，后台计划绝不修改Canon。

C驭兽第9回合遇到计划仍pending，直接用旧计划/当前Canon继续，没有前台Brain调用；第17回合使用ready计划。两次后台计划完整trace分别82.408秒和42.664秒（旧摘要31.58/24.17秒不符合最终trace，已更正），模型成本仍存在，只是不能当作玩家又等了这些时间。过期或不用的计划是明确成本取舍，不能只报快而不报浪费。

浏览器轨迹20个提交中，19次有完整帧计时：即时反馈中位约25.7ms；首个叙事SSE约11.37s；真正可见的两帧约11.38s；完成约26.08s；建议可见约26.14s。第16回合在浏览器runner未完成写记录前已提交，恢复时通过独立Player动作+服务器提交trace精确核对，计数一次，但不补造任何浏览器计时。原开局工具错误保留为失败。P95、各阶段、API与浏览器区别和每条完整轨迹壁钟时间见FINAL_MATRIX与PHASE_TRACES。

全部10条成功等待与完整壁钟结果已列入`artifacts/reports/ascension-v090/LATENCY.md`。3条prefetch轨迹共6次checkpoint：4次ready复用、2次未就绪fallback，均无前台Brain；6次后台计算367.097秒，其中2次未采用合计182.500秒。这是并行计算开销，不是新增玩家等待，也不是已知计费金额。

这些不是总体因果加速的随机A/B：世界、动作、采样、并发与基础设施状态会影响总体等待。更窄但成立的架构证据是checkpoint路径不再等待Brain。ACP setup、Narrator生成、偶发服务失败仍是长尾；SQLite不是主要慢点。并未测物理屏幕paint、WAN全链路、计费token或真人留存。

## 一致性与失败取舍

可重复验证的状态bug：多件物品用掉一件，`update.qty`原来被忽略。现定义为剩余件数；省略qty仍保留半瓶/半包容器计数，update不得增加件数。已用原真实两束苦叶根形状复现known-bad，再通过旧半包和新计数回归。不建立重量/第二库存系统。

B还有明确只询价却扣钱，以及新采货已经卖掉仍留在inventory的矛盾。D补了净结算与授权边界；E补已付订金不可重复扣。语义约束不等于确定性交易引擎，这类提案仍可能出错，不能宣称经济系统已经形式化正确。旧能力描述在突破后仍可能残留低阶限制，D补要求improve已有条目而非只追加新条目。

无效尝试已记录：A不足以推动长期成长；在已经停滞的共享ACP worker上关闭无关插件未解决故障；原配置短时恢复也很快，不能据此归因插件。随后受控空闲worker恢复与测试角色专用无工具配置降低了进程膨胀，但桥接版本在任务期间外部从1.6.2变为1.10.0，存在混杂。没有改全局认证、模型或其他项目配置，没有删除失败或批量杀不明Agent。第一次星图启动用了不存在的powerId，0回合失败保留；随后按实际目录选择天赋，不算恢复了一条不存在的Canon。

## 生产纪律与下一阶段

本轮没有更改public移动布局、字号、历史DOM策略、滚动锁、dock/Stop、IME或RTL结构。独立Native worktree不动。没有新增每N回合升级、通用身份树、奖励配额、第二库存、每回合judge/rewrite或旧TGN整套pipeline。蒸馏库和旧TGN只读，运行时没有全库检索。

最终接受版本仍部署原4317与原owner-only域名，提前备份真实SQLite并逐表hash核对旧游戏/世界快照/回合/Canon/计划，具体结果必须来自DEPLOYMENT回执。原始私有数据库、语料、原著、账号、密钥与隐藏推理不提交；仓库只保留合成实验正文、显式Player决策、净状态和阶段元数据。

下一阶段的高价值问题不是再加一个成长字段：已有能力如何改变生活安排、收入/资源自主权和他人主动行为；新地图不要再引入一串验证服务；有了足够资源时第二刻式/独有体系是否真的完成；重要突破如何获得克制而明确的视觉反馈。单次物理突破已经可见，长期人物不可替代性与社会相变还没有充分成熟。
