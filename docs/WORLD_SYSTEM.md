# 世界系统：定义、游玩与证据

更新：2026-09-07，v0.7.0。五语世界定义与身份约束见 `I18N_BACKEND.md`，最新语言证据见 `I18N_EXPERIMENTS.md`。发布/冻结结论以 `V060_RESEARCH_AND_EXPERIMENTS.md` 最新实测段为准；本文说明实际实现，不宣称已达到成熟长篇质量。

## 从一句话到可玩的世界

`GET /api/worlds` 返回五套作者预设与已完成的自建世界。预设直接使用本地定义，没有创建世界的模型等待。

`POST /api/worlds/custom` 接受 `{prompt, requestId}`，prompt 为1—2000字符。一次 World Forge ACP 调用生成紧凑世界定义，完成确定性结构校验后才写 SQLite。SSE 阶段为 `world_generation`、`world_validation`、`world_persistence`，最终 `complete {world, metrics}`；错误和取消没有替代文本，也不会保存不完整世界。相同已完成 requestId/描述只重放同一世界，改描述复用该ID返回冲突。浏览器取消会中止待完成的调用；已提交结果仍可从目录恢复。

世界定义包括背景/题材、独立力量来源和成长因果、连续大阶及各阶常识对标/新用途、三个天赋、当前开局位置/人物欲望/机会、以及真正属于主角的物品/货币/初始能力。不是把“烬河”替换成别的标题。

`POST /api/games {name, worldId, powerId}` 创建角色并保存完整世界快照；后续世界目录的编辑不会回写旧角色。预览只返回公开字段，不暴露未来计划与隐藏开局资料。

## 作者预设与同人标识

`烬河照夜`（边城修行）、`云背群岛`（驭兽与空域）、`灰塔星契`（魔法）是原创。

`赤曜药州` 借鉴《斗破苍穹》的稀有火种、功法演化和炼药推动突破；`万相猎庭` 借鉴《斗罗大陆》的本命形态、关键资源与新技能结合。明确显示“非官方同人灵感”及关联作品；当前人物、地名与开局是重新创作，不能说是完整复刻原著宇宙、官方产品或已取得授权。自建 prompt 可提到熟悉的作品；生成器必须标明非官方，不复制原文章节。

## Canon 与成长

`worlds` 表保存完成的自建定义与请求结果；`game_worlds` 保存每本新书的不可变定义快照。既有v0.5烬河存档没有快照时，使用原来的legacy定义读取，不改其状态、剧情或历史事件。没有迁移框架或新租户系统。

回合流程仍为：当轮行动 → 作者开局底稿或低频规划 → 一次流式Narrator正文+delta → 确定性应用 → 事务提交。第9回等检查点才规划，错误至多一次条件修复；没有每回合额外评审agent。生成预览不是正史，只有成功提交后的状态与正文才进入历史。

境界按角色世界快照验证，不共享全球修仙阶梯。`realmProgressDelta`每步0—20，到100且满足当前世界条件才能进入紧邻下一阶。`capabilities` 保存已经掌握的具体动作、限制、来源；`capabilityOps=add/improve` 让获得与强化在后续仍可用，而不是每轮重发同一奖励。数据库只能验证结构与明示规则，不能保证模型在语义上永不违背力量边界。

v0.6真实第五回合曾把“小半包药”写成“整包已空”。v0.6.1补充 `inventoryOps=update`：部分使用仍保留一包/瓶的数量，在description里记录剩余；整件用尽、交出或留下才remove。update不能生成未持有物，界面显示剩余描述。没有增加小数计量或无用物品分类架构。

## 从本地参考中实际借鉴什么

原TGN核心价值观只读参考 `PIPELINE_METHODOLOGY_AND_VALUES.md`：Fantasy First、Agency First、叙事复利、少而深的规则。不移植原生产的批量规划、审批工作台或完整蒸馏库。

协调者实际阅读《斗破》第15章《修炼》的连续原文；完整读取收据在研究报告。支持的启发是：压缩重复训练微操作，把时间、消耗、当前力量和下一层用途联系起来，再让收益进入有利害的行动。不是每轮发等级，也不是只把练习从+1改成+20。

下载提示词只作为二手设计资料。本轮明确读取了 `博主私藏提示词分享/玄幻背景/斗破苍穹-提示词.txt` 的力量/突破/物品部分，以及 `斗罗大陆-提示词V2.0.txt` 的修炼—关键资源—新技能—下一节点部分。它们启发了持续技能状态与突破用途展示；没有通读所有下载文件。没有把未经打开的搜索截断片段算作阅读。

不采用原提示词的逐字NPC回应、固定原著主角路线、海量LaTeX面板、每回合重复全设定、与成长无关的恋爱数值、未成年角色安排或权限绕过要求。原始提示词、原著及私人数据不进入Git，也不被整包塞进每回合上下文。当前没有接入在线GBrain检索；使用的是本轮读取后的短原则与作者定义，不能声称运行时自动学习了整个库。

## 计时与适用边界

创建世界是一次性等待，与角色开始后的首段正文和整回合完成分别测量。World Forge的ACP准备是generation内部子阶段，不重复相加。预设不伪造创建耗时；完成请求的幂等重放也不是一次模型加速。

首轮完整世界定义实际耗时60.824秒；v0.6.1把世界定义目标从2200—3800压缩至1100—1700中文字符，保留同一字段与校验，不减少为一个换皮简介。后续速度/质量以真实重测为准，不以目标字数直接宣布成功。

目前模板通常定义5个大阶（校验允许4—8），足以测试早期路线，不表示所有题材的百章成长、跨阶尺度、未来自动扩展都已验证。部署仍为单owner的私有MVP；没有匿名多用户、版权内容库、社交广场、图片、语音、付费或长期保活编排。下一位LLM首先读handoff和实测报告，再决定针对哪个已出现的问题改动。
